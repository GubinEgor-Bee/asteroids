## 📝 Описание проекта
Двумерная аркадная игра «Астероиды». Игрок управляет космическим кораблем, уничтожая процедурно генерируемые астероиды. Реализована сложная физика: инерция, тороидальная геометрия пространства и система частиц для взрывов.

## ✨ Функциональные возможности
### Основной функционал
- 🚀 **Управление:** Вращение корабля (стрелки влево/вправо), ускорение (стрелка вверх), стрельба (Пробел).
- 🌌 **Физика:** Корабль испытывает сопротивление среды и плавно останавливается при выключенном двигателе.
- 🍩 **Тороидальная геометрия:** Объекты, вылетающие за край экрана, появляются с противоположной стороны.
- 💥 **Взаимодействие:** Уничтожение астероидов ракетами, столкновения, система жизней и очков.
- 🎮 **Состояния игры:** Стартовое меню с интерактивной заставкой и экран Game Over[cite: 4].
