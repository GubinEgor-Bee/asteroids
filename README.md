## Описание проекта
Программа представляет собой двумерную аркадную игру «Астероиды»[cite: 4]. 
Игрок управляет космическим кораблем, уничтожая процедурно генерируемые астероиды с помощью ракет[cite: 4]. 
Реализована сложная физика с инерцией, тороидальной геометрией игрового поля и анимацией взрывов[cite: 4].

## Функциональные возможности
### Основной функционал
- 🚀 Управление кораблем (вращение, ускорение, стрельба)[cite: 4]
- 🌌 Реалистичная физика (сопротивление среды и плавная остановка при выключенном двигателе)[cite: 4]
- 🍩 Тороидальная геометрия (прохождение сквозь границы экрана)[cite: 4]
- 💥 Система столкновений ракет и корабля с астероидами[cite: 4]
- 🎮 Состояния игры (стартовый экран с кликабельной заставкой, игровой процесс, Game Over)[cite: 4]

## Установка и запуск
### 1. Клонирование репозитория
```bash
git clone [https://github.com/GubinEgor-Bee/asteroids.git](https://github.com/GubinEgor-Bee/asteroids.git)
cd asteroids

```

### 2. Создание и активация виртуального окружения

Windows:

```bash
python -m venv venv
venv\Scripts\activate

```

macOS/Linux:

```bash
python3 -m venv venv
source venv/bin/activate

```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt

```

### 4. Запуск программы

```bash
python main.py

```

### 5. Управление

* **Стрелки влево/вправо** — вращение корабля


* **Стрелка вверх** — включение двигателя (ускорение)


* **Space (Пробел)** — выстрел ракетой


* **Левая кнопка мыши** — начало игры при клике по заставке



## Структура проекта

```text
asteroids/
├── .gitignore
├── README.md
├── requirements.txt
├── main.py
└── src/
    ├── __init__.py
    ├── config.py
    ├── models.py
    └── app.py

```

**Назначение основных модулей:**

* `main.py` — точка входа в программу


* `config.py` — глобальные игровые параметры и константы


* `models.py` — математические модели игровых объектов (корабль, астероиды, ракеты) и физика


* `app.py` — контроллер приложения (игровой цикл, рендеринг, обработка событий)
